# Parenting Chatbot RAG Data

육아 상담 대화형 챗봇에 사용할 RAG 지식데이터입니다.

## Files

- sources.json: 육아 상담 데이터셋 출처 목록
- parenting_guides.json: 실제 육아 상담 RAG 데이터셋

## Usage

HTP 검사 결과 리포트를 본 부모가 아이의 상태에 맞는 양육 방법을 질문할 때 사용합니다.

## Rule

- 원문을 그대로 복사하지 않습니다.
- 출처가 확인된 자료만 사용합니다.
- 부모 상담용 행동 가이드로 요약·재구성합니다.
- 의료 진단, 치료, 약물 조언은 포함하지 않습니다.
- 아이의 상태를 단정하지 않고, 부모가 실천할 수 있는 양육 방향을 안내합니다.
